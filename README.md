## 📖 Descripción
Este proyecto consiste en una calculadora básica desarrollada en Java, que permite realizar operaciones matemáticas fundamentales y una operación científica adicional (potenciacia).  

El objetivo es aplicar los conceptos de **Programación Orientada a Objetos (POO)** como clases, objetos, herencia, polimorfismo y manejo de excepciones.

---

## ⚙️ Funcionalidades
- Menú interactivo con opciones para:
  - Suma
  - Resta
  - Multiplicación
  - División (con manejo de división por cero)
  - Potenciación (calculadora científica)
  - Salir del programa
- Validación de entradas numéricas con `try-catch`.
- Uso de un arreglo simple para mostrar categorías.
- Bandera booleana (`flag`) para controlar el ciclo del menú.

---

## 🏗️ Clases utilizadas
- **Main**: contiene el menú principal y la lógica de interacción con el usuario.
- **Calculadora**: clase base con operaciones básicas.
- **CalculadoraCientifica**: subclase que hereda de `Calculadora` y agrega la operación de potenciación.
- **DivisionPorCeroException**: clase personalizada para manejar errores de división entre cero.

---

## 💡 Conceptos de POO aplicados
- **Encapsulamiento**: atributos privados y métodos públicos para acceso controlado.
- **Herencia**: `CalculadoraCientifica` extiende de `Calculadora`.
- **Polimorfismo**: sobrescritura del método `mostrarTipo()` en la subclase.
- **Manejo de excepciones**: uso de `try-catch` para errores de entrada y división por cero.
